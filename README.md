# Free Claude skills

Ready-to-install skills from the videos. Each ZIP in the downloads folder is one skill. Free to use and change.

## Install a skill in two minutes

1. Download the skill's ZIP from the [`downloads`](downloads) folder, for example `sound-like-me.zip`.
2. In Claude (web or desktop), go to **Customize > Skills** and upload the ZIP.
3. Turn the skill on. Claude uses it by itself when a job matches, or you can ask for it by name: "Use the sound-like-me skill to reply to this."

Using Claude Code? Copy the skill's folder into `~/.claude/skills/` instead.
